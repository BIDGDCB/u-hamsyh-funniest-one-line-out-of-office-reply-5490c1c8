`main.ts` writes the funniest one-line out-of-office email reply to
`/output/entry.txt`. The line is validated before it is written: 1 to 160
characters, a single line, not only white space, and no control characters.

The entry line:

> I am out of office, which is the polite way of saying the emails can wait and so can you. Back Monday, probably.

## Run it

```sh
node main.ts
```
